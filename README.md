# Portfolio

A static personal portfolio website built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve the project directory with any static
web server.

## Deploy with GitHub Pages

1. Open the repository's **Settings**.
2. Under **Pages**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.

The site will be available at the URL shown in the Pages settings.
